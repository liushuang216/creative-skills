# 视频角色替换

把原视频中的指定角色替换为新角色，同时保留用户要求的表演、摄影、场景与剪辑。支持单人、多人、人形或非人形角色。默认保留原视频结构；用户明确要求改变风格、场景或动作时，只调整指定范围。

## 核心判断

- 实际查看视频或抽帧，不能从标题、文件名或音乐名推断道具和动作。无法查看时说明观察缺口，提供待核对草稿，不编造逐帧结论。
- 用稳定的原角色标识建立映射，例如“原角色 A（条纹上衣、短发）→新角色 X”。开枪者、受击者、胜者、倒地者都是临时行为，不能替代身份；左右位置也不能替代身份。
- 图片负责新角色的识别特征，视频负责原角色的姿态、表情、视线、动作、遮挡、身体朝向、道具与镜头。分别说明每份参考的职责。三视图只是同一角色的不同角度，不继承白底、并排布局和静态站姿；生成补全的背面不是官方设定。
- 将“身份不变”与“姿态可变”分开：脸部与服装识别点保持；卡通动作允许参考片驱动的挤压、拉伸、弯折和回弹。写实片按真实动作和适配范围处理，不自动添加卡通变形。
- 身体朝向、支撑点、受力和遮挡服从原表演。不能为展示正脸把俯卧改成仰卧，或把背影转成正面。允许合理遮脸。
- 每次生成的 prompt 都独立完整，只引用本次上传的素材，不写“同上一段”“接下一段”。项目层面可记录跨段衔接，但不要把未提供的上下文交给生成模型。
- 请求仅限 prompt 时不自动生成视频。付费提交、重试及外部上传按用户授权执行；历史项目中的授权不沿用到新项目。

## 按需执行

### 1. 明确输入与范围

查看参考片、新角色图以及已有结果。只询问会改变执行的缺项，例如无法判断的角色对应。记录：

- 原角色到新角色的稳定映射及需要保留的辨识点。
- 用户要 prompt、分段素材包、结果检查、局部修复还是成片。
- 实际文件的尺寸、帧率、时长及音轨；制作分段或剪辑时用媒体探测工具读取，不相信文件名中的“4K”。
- 使用入口的时长、素材数量等限制。未知时将限制参数化，不把某个平台历史限制当成通用规则。

### 2. 观察镜头与角色归属

先总览，再在切镜、遮挡、局部特写、互动与疑点处加密查看。闪光、快速动作和遮挡可能被误判为切镜，需核对前后帧。

为各镜头记录：起止时间、原角色标识、新角色、局部归属、前后空间层次及必要动作节点。只写观察到的内容。复杂同框分别标注前景手、背景人物、背影和身体局部，不仅标注画面中央主体。

视频可直接承担动作细节时，文字主要解决身份歧义和已知失败，不用长篇重复描述制造冲突。按 [references/prompt-template.md](references/prompt-template.md) 输出直接使用稿。

### 3. 需要时再分段

仅当长度超限或用户要求分段时执行。读取 [references/segmentation-and-review.md](references/segmentation-and-review.md)。

优先在原有真实切镜处拆分，保持时间线连续；同一长镜头超限且没有合适切点时说明限制并协商拆法，不凭空创造切镜。每段 prompt 时间从零起算。分段在切镜处衔接仍然是多镜头剪辑，不称为“一镜到底”。

不要默认添加出场 PV 的英雄定格、慢动作、片尾落版或淡出。起止姿态应对应当前参考片实际首尾。

### 4. 生成结果检查与局部修复

对照参考片与生成结果，区分身份错误、表演偏差和用户允许的变形。不能仅凭极端姿态判断“肢体错误”。

发现问题时读取 [references/repair.md](references/repair.md)。优先保留可用镜头，选取能解释动作与空间关系的最小完整镜头或镜头组修复。不要把单个错误帧当成完整修复范围，也不盲目重做全片。

### 5. 回填与交付

只有用户要求剪辑时才回填、统一参数和拼接。按实际生成片动作锚点确定入点与出点；不默认超出参考长度的内容全是尾部停顿，不靠整体变速掩盖节奏错误。

prompt 任务交付：
- 本次素材标签与职责。
- 可直接复制的独立 prompt；必要时附镜头归属表。
- 有实质影响的未确认项。

分段或修复任务额外交付：
- 对应参考片、时间线或帧范围，以及明确的回填位置。
- 验证范围：采样视觉检查、逐帧核对、听审、音画同步或解码检查分别是否完成。

保留原始素材，避免覆盖唯一源文件。公开分享本技能时使用通用角色标识与合成示例，不打包实际项目视频、角色素材、资产 ID、个人路径或会话记录。
