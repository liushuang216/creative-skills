# 分段、核对与拼接

## 分段记录

探测原文件参数，并选择能满足当前生成入口限制的真实切镜点。自动场景检测只提供候选，闪光和高速运动需要人工排除。

固定帧率片可用半开帧区间记录：`[start_frame, end_frame)`。相邻区间的结束帧应等于下段起始帧，帧数为差值。变帧率片用实际时间戳定位，不直接以时间乘平均帧率求精确帧号。

建议按实际需求保存：

| 字段 | 含义 |
| --- | --- |
| segment_id | 稳定段号，不用下载顺序推断 |
| source_start / source_end | 原片时间范围 |
| start_frame / end_frame | 固定帧率下可验证的半开区间 |
| local_shots | 该段从零起算的切镜与角色映射 |
| reference_file | 本次上传的视频 |
| first_frame / last_frame | 起止检查图 |
| audio_policy | 生成音轨、原音轨回贴或其他指定方案 |

不强制为只要 prompt 的用户制作完整素材包。

需要逐帧精确切割时，不默认流复制能在任意切点准确起播；关键帧位置可能影响结果。以导出的实际解码帧核对首尾和数量，并检查有无重复、遗漏或黑帧。单独处理原片片尾标识或字幕须符合用户范围，不擅自删除。

## 检查生成结果

先用内容匹配段号，再读取实际时长、分辨率、帧率和音轨。全片采样用于筛查，疑点加密检查：

1. 身份：反打、背影、遮挡后再入画、局部特写和反转后是否对应原角色。
2. 表演：准备、冲击、形变、回弹与落点是否保留；不能将受击反应泛化成跳舞。
3. 空间：人物是否留在原片对应区域；前后层次、胸背朝向、持握和支撑是否正确。
4. 连续性：服装、配饰、道具和参与者数量是否漂移。
5. 剪辑：切点与动作锚点是否对齐，首尾是否多出保持、漏掉动作或新增镜头。
6. 声音：是否实际听审、是否核对关键动作同步；未听审就不要声称音画通过。

发现问题时记录参考时间与生成时间，两者不能混用。相同时长不保证相同节奏。

## 回填与拼接

- 优先替换完整错误镜头或有上下文的镜头组，保留其余可用内容。
- 生成入口只支持整数秒时，确定参考动作应落在哪段时间，再检查实际输出。不得默认将所有多余长度直接尾裁。
- 原片与生成片帧率不同，分别记录帧号和时间，不直接沿用原片帧号切生成片。
- 统一最终尺寸、时间基准和编码；变速、插帧或裁画面会改变观感，采用前先判断是否必要。
- 若回贴原音轨，先对齐动作锚点；最终动作节奏已变时不能直接回贴后声称同步。
- 验证最终文件可完整解码、规格符合要求，检查拼接点和音轨。只做了采样就报告采样范围。
- 超分是可选后期，用户需要时单独处理；不能把普通插值放大称为恢复原生高清，也不能继承旧项目工具路径。

## 通用素材目录

项目需要归档时可采用：
`source/`、`characters/`、`segments/`、`prompts/`、`generated/`、`repairs/`、`final/`。

按依赖和用户需求调整，不创建空目录占位；缓存清理不得删除唯一源片和仍被回填工程引用的文件。
