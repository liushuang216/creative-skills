# 独立分段提示词模板

根据实际素材替换占位符，删掉不适用的段落。角色数量不固定；以下以两名角色为例。镜头时间必须来自观察或测量，不能套用示例时间。

## 提交稿

```text
根据 @视频1 制作 {时长}、{画幅} 的角色替换视频。保留参考视频的 {场景、镜头顺序、切镜时刻、运镜、动作、表情与节奏中用户要求保留的项目}，替换指定角色，不重新编排剧情。

【固定身份与素材职责】
原角色 A（{稳定外观识别线索}）始终替换为 @图片1 的角色 X。
原角色 B（{稳定外观识别线索}）始终替换为 @图片2 的角色 Y。
映射随原角色身份追踪，不随画面左右、道具持有者、攻击与受击关系或剧情输赢重新分配。

@图片1 只控制 X 的 {关键辨识点}。
@图片2 只控制 Y 的 {关键辨识点}。
@视频1 控制姿态、视线、表情、身体朝向、动作时序、道具、空间、镜头及剪辑。
{若图片为三视图：每张图只代表一个角色，不继承白底、并排布局和静态站姿。}
原角色的脸、服装和身体局部均按对应新角色替换；背景路人与其他未指定对象按用户范围处理，不新增角色副本。

【逐镜头归属】
以下时间从 @视频1 首帧起算，以实际切镜为准；每个镜头保留内部连续动作。
{起点–终点}｜{原角色 A/B → X/Y；前景、背景、背影、手脚等局部归属；必要动作或空间限制}
{按实测镜头继续，不遗漏反打、局部与同框镜头。}

【表演与空间】
优先匹配原片的姿态轮廓、重心、视线、表情和动作节拍。
{卡通表演：允许动作驱动的挤压、拉伸、弯折及局部放大，参考片保持极端姿势时持续保持，到对应节点再回弹；不强求静态参考比例。}
{写实表演：保持合理的人体结构和运动范围，在新角色身体条件下适配原动作。}
保持关键识别特征、服装与附属物连接，不因变形增殖肢体或交换身份。
{只写当前片段有风险的朝向、支点、接触、遮挡约束。不要要求全片始终露出正脸。}

【道具与场景】
{道具外观、数量、持有者和运动关系按当前镜头观察填写；道具转手时按原片转手。}
身体变形不意味着刚性道具一起变软；手或前爪与接触点的关系稳定，不凭空增加持物肢体。
{用户要求的风格与场景处理。替换角色的光照、阴影和接触关系与环境协调。}

【起止与声音】
首末帧分别对应本次参考片的构图、角色位置和动作进度，到参考片终点直接结束。
{声音方案：保留节拍供后期回贴原音轨 / 生成同步音效 / 按用户提供对白处理。}
不擅自新增剧情、慢动作、定格、淡出、黑场、旁白或文字。
```

## 写作取舍

- 每镜只写需要消歧的内容；已有视频能清楚控制的连续动作不反复铺陈。
- 反转时明确“倒地的是 Y，站立的是 X”，但身份定义仍然是原角色 A/B。
- 道具可能短暂无人持握、被转交或被身体遮住，不强制全片由同一角色手持。
- 参考人物手部特写应替换为新角色相应肢体，不把残留人手误当成可保留道具。
- 帧率、时长写入 prompt 只是目标；交付仍需检查生成文件实际参数。
- 声音策略与视频生成能力分开：要求参考声音节拍不等于生成文件包含原音轨。
