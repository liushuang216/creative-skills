# 局部修复

先定位症状，再建立正向约束。不要只堆“禁止变形”“禁止穿模”；允许的夸张变形不是身份错误。

| 症状 | 优先明确 |
| --- | --- |
| 串角或反转后换错 | 原角色的稳定标识与映射；每镜前景、背景和局部归属 |
| 原人手、袖口残留 | 局部属于哪个角色，应替换为何种肢体 |
| 受击变成普通舞蹈 | 冲击发生 → 身体压缩 → 指定方向反弹 → 保持或恢复的可观察节点 |
| 俯卧变仰卧 | 胸腹朝地、背部朝上、手掌支点、肩颈与骨盆连续方向；允许遮脸 |
| 角色跑到另一侧场景 | 当前镜头空间地标、人物所在区域、退镜后的深度位置 |
| 持物关系错误 | 当下持有者、接触点与道具轨迹；不要强制所有镜头手持 |
| 片尾被加定格 | 结束时动作进度对应参考末帧，不额外增加停顿 |

## 修复范围

选取最小但足以交代身份、动作和空间的完整镜头组。单镜缺乏上下文时，带上前一镜的起势或后一镜的落点；不固定为 2 秒、4.5 秒等历史案例长度。

参考来源必须明确：
- 原片控制动作与镜头。
- 角色图控制身份外观。
- 可用生成帧如被采用，只控制已验证的风格、光色或服装表现。
- 错误生成视频只作问题定位，不让模型继承其串角或错误朝向。

如果需将短参考放慢以适配入口，记录时间缩放关系；修复生成后依据动作核对恢复节奏，不能假定模型严格遵守倍率。

## 简短修复稿模板

```text
参照 @视频1 生成 {时长、画幅} 的角色替换视频，保留这组镜头的切换、运镜、动作顺序与场景。

@图片1 控制角色 X 的外观，替换原角色 A（稳定标识）；
@图片2 控制角色 Y 的外观，替换原角色 B（稳定标识）。
{可选 @图片3 的单一职责及禁止继承内容。}

本次视频内时间：
{实测起止}：{角色归属与该镜关键动作关系}。
{实测起止}：{错误镜头的正向描述，例如胸腹朝地、双掌支撑并连续撑起；允许头发遮脸。}
{实测起止}：{后续动作及结束姿态}。

{仅针对本次问题的身份、形变、道具和空间约束。}
从参考首帧执行到末帧，不增删镜头或添加结尾停顿。
```

## 回填说明单独交付

在生成 prompt 外说明：原成片被替换的起止时间、修复参考的时间范围、生成后预期采用范围，以及动作未对齐时需重新核对的节点。它们是剪辑信息，不要求模型理解未上传的完整成片。

修复后检查问题镜头及两侧接缝；未修的区域不因一次局部修复而自动视为验证通过。
