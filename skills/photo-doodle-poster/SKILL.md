# 独立照片手绘海报

将照片转成艺术杂志或艺术出版物风格海报。一张输入对应一张独立输出，不做多照片拼贴。用户只要 prompt 时交付可直接使用的提示词；用户要海报时调用当前环境可用的图像编辑工具，传入对应原照片。

## 核心约束

- 默认画布为 3:4 竖版，上下区域各占总高度 50%，分界在 y=50%。例如 1536×2048，分界为 y=1024；每个半区实际是 3:2 横向区域。
- 上半保留原始照片的主体身份、结构、姿态、真实材质、自然光影和色彩氛围，仅做轻微杂志调色。
- 默认上下两区都保留主要主体在原图中可见的完整轮廓。人物特别检查头、伸出的手、腿、脚和鞋；保留原本遮挡，不臆造不可见肢体。原图本来就是半身时，不擅自补成全身。
- 适配横向半区时，先等比例缩小完整主体，再自然扩展周围环境。不得为了铺满上半区裁掉原图可见的肢体、拉伸人物或改变姿态。在手脚等轮廓末端留安全空间。
- 下半删减的是次要角色、背景、服饰细节和道具，不是主要主体的腿脚。用户明确要求局部或裁切设计时才采用局部主体。
- 下半不复制场景：只保留最有识别性的主体、姿态和必要叙事关系，重新组织位置和尺度。
- 对前后遮挡或错位照片，先识别真实主体归属，保留遮挡带来的叙事关系；不把重叠误当成身体融合，不补画看不见的人脸或肢体。
- 采用 Hand-drawn Doodle Lifestyle Illustration / Naïve Illustration / Marker Drawing：轻微抖动、断续、松弛的线条，马克笔、蜡笔或油画棒式自然涂色，允许越线、露白和手工误差。
- 大面积有意识留白是核心。可将约 75–85% 的下半区保留为空白作为构图目标；这属于审美指导，不是未经测量的精确验收值。通过缩小完整主体获得留白，不靠删腿脚实现。
- 下半只用 2–3 种主色＋黑或深灰线条＋暖白纸底。颜色从照片中提取，舍弃多余颜色；不把这个限制错误应用到上半照片。
- 图形与文字共同构图：隐形网格、视觉轴线、阅读路径、偏心与不对称呼应。少量自然手写短句，可配极小辅助文字；不机械居中，不堆叠长文。用户要无字则完全去字。

用户当前指定的比例、文字、颜色和裁切要求优先于默认值。

## 执行

1. 查看每张原照片，识别主要主体、可见轮廓、姿态、关键关系和 2–3 个色彩记忆点。多图分别处理；不要把不同照片当成同一个主体的多角度参考。
2. 阅读 [references/prompt-template.md](references/prompt-template.md)，替换主体、保留项、删减项、配色、文字和位置；不要将示例人物、服装或秋日文案套到所有照片。
3. 提示词先写主体完整性与上下等分，再写风格与排版。需要对照原始审美要求时，阅读 [references/original-prompt.md](references/original-prompt.md)；其中允许局部裁切的表述已由上述默认完整性规则收紧。
4. 用支持参考图编辑的图像工具生成。遵循所在环境的图片传入和结果展示方式；工具不可用时交付提示词并说明尚未生成。不要用文字描述假装已经生成海报。
5. 查看结果并与原图对照：主要主体有无被截断或变形，上下是否等分，下半是否过大、过满、颜色过多，文字是否准确。出现缺腿脚时，回到原照片，强调“整体缩小＋扩展环境＋保留完整轮廓”；避免只在错误结果上臆造肢体。
6. 区分视觉检查和像素测量。若要求严格可打印尺寸或精确分界，核验实际文件尺寸与分界；不能验证时如实说明，不声称像素级通过。

交付每张独立海报，并按需附对应的最终 prompt。公开分享 skill 时仅打包通用说明和去个人化模板，照片、生成的人像和本地路径不属于默认分享内容。
