# 实景延伸线稿旅行海报

一张照片对应一张海报。先观察照片，再从真实场景中找到能延伸到纸面的元素，让摄影与小故事通过同一条线连接。用户只需要提示词时交付可直接使用的 prompt；需要图片时使用支持参考图的图像编辑工具。

## 构图与保留项

- 默认 3:4 竖版，上方约 60%–70% 为真实摄影，下方为干净暖白象牙纸面，只有极轻微纸纹和大量留白。不是严格上下等分，也不设置机械分隔线。
- 保留原有主体、人物、建筑、姿态、遮挡、光线、色彩与空间关系。只为适配画幅做必要的等比例裁切，不默认扩景、重构摄影内容、调色或拉伸。尽量保护重要肢体与主体特征；若固定分区与用户要求的完整保留无法兼得，说明冲突并询问取舍，不悄悄补景或变形。
- 遮挡和错位摄影要保留真实归属；不补画隐藏人脸，不把前后重叠解释为身体融合。
- 根据照片选择一个真实存在且适合延伸的元素，如道路、海浪、河流、小径、桥梁、建筑或山坡轮廓，也可以是缰绳等现有线性物件。不要为套用玩法凭空制造道路、码头或绳索。
- 连接元素从照片中的对应位置顺势跨入纸面，沿原有方向与透视逐渐简化为手绘线。衔接处可轻微不规则，但不能用大面积模糊掩盖断线或改变位置。

## 小人与互动

- 下方只加入一个小比例钢笔线稿人物，默认高度约为整张画面的 7%–10%。轮廓纤细、略不规则、松弛自然；五官不清晰，服装与道具简化。
- 动作必须由当前元素决定：沿道路推车、拉住海浪化成的线、坐在延伸码头边、攀爬山坡轮廓、牵住延伸的缰绳等都只是例子，不固定套用某一种故事。
- 明确接触点与支撑：脚落在路面或极少量地面轮廓上，坐姿有承托，抓握确实接触线，受力方向与身体倾斜相符。避免悬浮、穿透、断开的手和线。
- 默认黑色线稿；场景需要时，只让连接元素保留一种来自照片的淡彩，其余纸面保持空白。不要把照片也减色。
- 添加一句与动作呼应的 1–5 个英文单词手写旁白，字号小且克制。用户指定原文则逐字使用，指定无字则完全去字。
- 画面追求诗意、简洁和编辑感。避免巨大人物、复杂五官、动漫风、密集线条、完整背景复刻、拼贴网格、边框、水印和过大文字。

用户当前指定的比例、文案、颜色与裁切要求优先于这些默认值。

## 执行与检查

1. 查看原图，明确要保留的摄影内容、连接元素的真实起点、穿越边缘的方向，以及小人的接触点、支撑点和动作。没有合适元素时先给出可行的简化方案，不臆造照片事实。
2. 使用 [references/prompt-template.md](references/prompt-template.md) 按照片填写提示词；需要逐项核对最初审美要求时读取 [references/original-prompt.md](references/original-prompt.md)。不要把示例里的马、缰绳或 “A little help” 套到其他场景。
3. 将原图作为编辑目标传入当前可用的图像工具；本地图片先按工具要求查看。多图逐张处理。只有文字能力或工具不可用时交付 prompt，并如实说明尚未生成。
4. 查看结果并对照原图：主体与色彩是否漂移，摄影占比是否合理，线是否从正确位置连续延伸，人物是否在 7%–10% 的视觉尺度内、抓握和落脚是否合理，纸面是否过满、文字是否准确。针对实际问题做局部修正，保留原图作为摄影依据。
5. 需要精确印刷尺寸时检查实际文件宽高；视觉估计的分区、人物比例和留白不能写成已完成像素测量。生成式编辑不保证原照片逐像素不变；用户明确要求像素不变时采用可保留原摄影像素的合成方式，或说明现有工具限制。

交付独立图片，按需附实际 prompt 与观察到的偏差。照片与生成结果仅在用户授权时公开；调用技能本身不授予发布素材的权限。
