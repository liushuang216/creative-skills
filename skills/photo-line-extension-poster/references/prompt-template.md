# 场景化提示词模板

先观察照片，替换所有花括号字段，再提交图像工具。上方摄影的保留项、连接元素的真实起点与下方小人的支撑关系最重要。

```text
将输入照片制作成一张独立的“实景延伸线稿旅行海报”，3:4 竖版。

上方约 {60%–70% 中的适合比例} 保留输入照片的真实摄影质感。保持 {主体、人物、建筑、姿态与遮挡关系}，保留原有光线、色彩与空间关系。仅为适配画幅做必要的等比例裁切，优先保护 {关键可见轮廓}。不拉伸、不重构主体、不默认扩展环境。

下方留出暖白象牙纸面，极轻微纸张纹理，大量留白。边缘允许轻微不规则的自然过渡，不加机械分隔线。

连接元素选择原图中真实存在的 {元素}。它从 {具体起点} 沿 {原有方向与透视} 顺势跨过照片下缘，逐渐简化为 {黑色细钢笔线 / 来自照片的一种淡彩线}，延伸至 {纸面上的接触位置}。保持同一个元素连续，不另画一条不相连的线，不复刻全部背景。

在纸面加入一个小比例黑色钢笔线稿人物，高度约占整张画面的 7%–10%。人物 {动作}，{手、脚或身体与连接元素的明确接触方式}；{落脚点、承托或受力关系}。无清晰五官，服装和道具简化，细线略不规则，自然松弛，不悬浮。

只添加这句英文手写旁白："{1–5 个英文单词}"
文字位于 {与动作呼应的留白位置}，小而克制。其余纸面保持空白。

整体诗意、简洁、有编辑感。不要巨大人物、复杂五官、动漫风格、密集线条、完整背景复刻、拼贴网格、边框、水印或过大文字。
```

若用户要求无字，删除旁白要求并明确“无文字”。不要保留花括号或给出互相冲突的分区比例。摄影占比、人物大小是构图目标，仍需查看实际生成结果。
