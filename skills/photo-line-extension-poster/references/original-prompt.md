# 用户提供的原始审美提示词

此玩法由用户收集后提供，按用户要求纳入网络收集玩法的来源说明。原作者及首发链接暂未提供，不作原创归属声明；如获知来源，可补充署名或按仓库来源说明联系处理。

将上传的照片制作成一张“实景延伸线稿旅行海报”，采用3:4竖版。上方约60%—70%保留原照片的真实摄影质感，保持原有主体、人物、建筑、光线、色彩和空间关系，只允许为适配画幅进行必要的等比例裁切。下方留出干净的暖白象牙纸面，带极轻微的纸张纹理和大量留白。

根据照片选择一个自然延伸的元素，例如道路、海浪、河流、麦田小径、桥梁或建筑轮廓。让这个元素从照片中的对应位置顺势延伸到下方纸面，逐渐简化为手绘线条。衔接处位置、方向和透视连贯，边缘可采用轻微不规则的纸面过渡。

在下方加入一个小比例黑色钢笔线稿人物，高度约占整张画面的7%—10%。根据场景设计一个简单、有故事感的动作，让小人与延伸元素产生明确互动，例如沿着道路推车、拉住海浪形成的线、坐在延伸的码头边，或攀爬山坡轮廓。小人必须有合理的落脚点或受力关系。

人物不描绘清晰五官，服装和道具简化，线条纤细、略有不规则，松弛自然。默认使用黑色线稿；若场景需要，可让连接元素保留一种来自照片的淡彩色，其余纸面保持空白。

添加一句1—5个英文单词的简短手写旁白，内容与画面故事呼应，字号小且克制。

整体诗意、简洁、有编辑感。不要将照片与插画机械分开，不要悬浮小人、巨大人物、复杂五官、动漫风格、密集线条、完整背景复刻、拼贴网格、边框、水印或过大的文字。
